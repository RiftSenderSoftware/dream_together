# Casual co-op multiplayer sample

## Description
This sample demonstrates how developers can use the Multiplayer
Services SDK APIs, ScriptableObjects and MonoBehaviour scripts
to connect two players in a multiplayer session using the Relay
service to obfuscate their connection information from each other.

For more information please visit the associated online [documentation](https://docs.unity.com/en-us/multiplayer/quickstarts/casual-co-op-quickstart).
